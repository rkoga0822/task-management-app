# 業務タスク管理アプリ

Laravelで作成したタスク管理アプリです。  
ユーザーごとにタスクを管理でき、認証・認可・管理者機能を実装しています。

## 機能一覧

### ユーザー機能
- ユーザー登録
- ログイン / ログアウト
- タスク一覧表示
- タスク作成
- タスク編集
- タスク削除
- ステータスによる絞り込み
- 自分のタスクのみ閲覧可能

### 管理者機能
- 全ユーザーのタスク一覧確認
- ユーザー一覧表示
- ユーザー名編集
- ユーザー削除
- ユーザー削除時、関連タスクも削除

### 認証・認可
- Laravel Fortify
- Policyによる認可制御
- 管理者権限判定

---

## 使用技術

- PHP 8.x
- Laravel 13
- MySQL
- Starter Kit
- Blade
- Tailwind CSS

---

## 工夫した点

- Policyを利用して認可を実装
- 管理者と一般ユーザーで画面を分離
- 他人のタスクへアクセスできない設計
- 絞り込み機能を実装
- リレーションを利用しユーザー削除時にタスクも削除
